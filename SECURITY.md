# Security Policy

## Reporting a Vulnerability

**Do NOT open public issues for vulnerabilities.**

If you discover a security vulnerability, please report it via [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository, or email us directly at **security@ilabs4u.com**.

## Response Timeline

- **Response time:** 48 hours
- **Disclosure timeline:** 90 days

We aim to address and resolve all reported issues within 90 days. We will coordinate with you to ensure the patch is released safely before any public disclosure.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |
| < v1.0  | :x:                |
